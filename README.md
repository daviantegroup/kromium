## 📌 Overview

This repository is no longer updated. All active development, maintenance, and future releases of **Kromium** are hosted and actively maintained by the development team at:

🔗 **[https://github.com/daviante-org/kromium](https://github.com/daviante-org/kromium)**

### 🚀 Actively Maintained

Kromium is **actively maintained and developed** by the core team. You will find:
* Continuous bug fixes and performance improvements.
* Up-to-date Chromium Embedded Framework (CEF) and JetBrains JCEF runtime integrations.
* Ongoing support for Compose Multiplatform Desktop and Universal Java desktop toolkits (Swing, AWT, SWT, JavaFX).
* Active response to community issues, discussions, and pull requests.
